# Madame Minute

Madame Minute is a React + Vite work journal dashboard with a TVA-inspired control-room interface.

## Run locally

```bash
pnpm install
pnpm dev
```

Then open:

```text
http://localhost:5180
```

You can also use `npm install` and `npm run dev`.

Do not open `index.html` by double-clicking it. Vite serves `/src/main.jsx` as a JavaScript module over HTTP; opening the HTML as `file://` causes the browser CORS error shown above.

## Production build

```bash
pnpm build
pnpm preview
```
